## About

```c
struct Developer {
    const char *name;
    const char *role;
    const char *focus[3];
    const char *toolchain;
};

static const struct Developer me = {
    .name      = "Cesar Real",
    .role      = "Embedded Software Developer",
    .focus     = { "Bare-Metal Firmware", "FPGA and SoC Design", "Systems Programming" },
    .toolchain = "C, GCC, Make, Linux, and a logic analyzer"
};
```

I write register-level C for microcontrollers, with no HAL and no external libraries,
and build the protocol layers underneath it by hand. BS in Computer Engineering with a
mathematics minor from North Central College. Happiest somewhere between a datasheet
and an oscilloscope trace.
